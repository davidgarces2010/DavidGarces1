El problema: lo que no se encuentra, no se usa

En el Taller de Electricidad y Electrónica hay muchos componentes, pero se usan menos de lo que podrían: es difícil saber qué hay y dónde está guardado. AutoComponent guarda los componentes y te lleva directo a ellos.

Lo buscas en el celular. El estante te lo señala.

Cómo funciona

  1. Abre la plataforma

    Entra desde cualquier celular con internet. No hay que instalar nada.

  2. Busca o escanea

    Escribe el componente o escanea su código QR. Creamos 85 códigos con información de cada uno.

  3. La app envía la señal

    La plataforma web le manda la orden de búsqueda a la ESP32.

  4. Se enciende el LED

    La ESP32 ilumina el LED del cajón correcto en la tira.
Celular → App web → ESP32 → Tira de LEDs → Cajón

La plataforma web

Desarrollamos la aplicación con Vento IA. Muestra el inventario, permite buscar componentes y envía la señal al estante.

Como es una página web, funciona desde cualquier celular con acceso a internet: estudiantes y profesores usan su propio teléfono.

La ESP32 y la tira de LEDs

1. Conexión. La tira de LEDs recibe datos por un pin de la ESP32 (en el ejemplo, el pin 5), comparte tierra (GND) y se alimenta con 5 V.

2. Programación. La ESP32 se conecta al WiFi y abre un pequeño servidor. Cada LED tiene un número.

3. Conexión con la app. Cuando buscas un componente, la app consulta su posición y llama a la ESP32 con ese número. Ella enciende solo ese LED.

// Pedido de la app a la ESP32
GET http://IP_ESP32/led?n=12

// En la ESP32
tira.clear();
tira.setPixelColor(n, tira.Color(255,200,0));
tira.show();

Código completo de ejemplo: esp32_leds.ino. Ajusta pin, número de LEDs y WiFi a tu montaje.

El reto de los costos: lo que nos enseñó el cartón

Un estante de madera con 85 cajones resultó demasiado costoso. Probamos con cartón y material reciclable: sirvió para validar la electrónica y el software, pero se daña con facilidad. El problema no está resuelto del todo porque aún no hacemos el prototipo final.
